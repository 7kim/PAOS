 TOP 8 IMPROVEMENTS NEEDED
──────────────────────────────────────────────────────────────────

 1.  Replace `any` types with proper interfaces (Q92)
     5 files use `: any`: MiniDagView.tsx, LoadPipelineDialog.tsx,
     TemplateBrowser.tsx, types.ts, Canvas.tsx — ~13 occurrences total.

 2.  Add explicit cycle detection error messages (Q21)
     Kahn's algorithm silently truncates cyclic pipelines. Need:
     if order.length < nodes.length -> return "Error: pipeline has cycle"

 3.  Add file read caching layer (Q56)
     Every API call re-reads files from disk. Add in-memory cache with
     5-second TTL for frequently-read files (META.json, queue.json).

 4.  Add DAG validation on every read (Q27)
     Validate: no missing node refs in edges, no duplicate IDs, all
     nodes have required data fields (agentId, prompt, label).

 5.  Add velocity tracking & trends (Q62, Q64)
     Track task completion rate (tasks/sec), estimate ETA from moving
     average of recent completion times.

 6.  Add similarity metrics for template matching (Q37)
     Implement cosine similarity on prompt embeddings and agent vector
     profiles for smarter template suggestions.

 7.  Add React.memo on child components (Q100)
     Missing memo wrappers on Canvas child components, FileTreeExplorer,
     TemplateBrowser — causing unnecessary re-renders.

 8.  Reduce prop drilling in nested components (Q4)
     Some deeply nested components receive full pipeline objects
     instead of narrow subsets of just what they need.
