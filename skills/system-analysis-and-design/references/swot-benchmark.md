# SWOT Benchmark Reference

The canonical SWOT document is at:
`~/AI_Workflow/SWOT-Benchmark.md`

This evaluates the project as an **investment** — its Strengths, Weaknesses, Opportunities, and Threats. Use it after the Coding Principles Benchmark to get the full picture.

## The Four Quadrants

| Quadrant | Questions | Scoring |
|----------|-----------|---------|
| Strengths | S1-S8 (architecture, correctness, UX, data integrity, extensibility, persistence, real-time, responsive) | 0-5 per area |
| Weaknesses | W1-W8 (type safety, error handling, duplication, tests, docs, coupling, state management, performance) | 0-5 per area |
| Opportunities | O1-O8 (marketplace, plugins, analytics, collaboration, export, CI/CD, benchmarking, self-healing) | Potential 0-5, Effort 0-5 |
| Threats | T1-T7 (competition, lock-in, tech decay, data loss, security, adoption, burnout) | Severity 0-5, Likelihood 0-5 |

## Output

- SWOT Matrix (quadrant summary)
- Top 3 per quadrant
- Investment recommendation: Buy / Hold / Sell
